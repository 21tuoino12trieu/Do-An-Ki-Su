# SDK Langfuse cũ để tham khảo

`langfuse_sdk_v2` là bản SDK 2.60.8 trước đây nằm trực tiếp ở `langfuse/` trong repo.

Đã chuyển vào đây để giữ mã gốc và tránh che khuất SDK chính thức cài bằng pip. Không thêm thư mục này vào PYTHONPATH hoặc dùng làm SDK khi chạy Beeflow.

SDK đang dùng và cách kiểm tra được ghi tại `docs/setup-langfuse.md` của workspace.
