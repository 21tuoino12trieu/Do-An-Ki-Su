# Các module được tách cho đồ án

- [Beedoc](beedoc/README.md): package chuyển HTML bài viết Confluence sang Markdown, theo [phạm vi thiết kế](../docs/design/modules/beedoc.md).
- [Beeflow](beeflow/README.md): core workflow, 15 node theo thiết kế và đầy đủ package Beegen đi kèm, bao gồm schema/operation/engine; đang chờ điều chỉnh phụ thuộc và kiểm chứng runtime.
- Mỗi module được tách có chọn lọc từ mã nguồn tham khảo và điều chỉnh cho phạm vi đồ án. Chi tiết nguồn gốc, cách chạy và giới hạn được ghi trong README của module.
